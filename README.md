
# Виджет банковских операций клиента

Проект для обработки банковских операций: фильтрации по статусу и сортировки по дате. Позволяет фильтровать транзакции по статусу (например, 'EXECUTED', 'CANCELED') и сортировать их по дате в прямом/обратном порядке.

## Установка

1. Клонируйте репозиторий:
```bash
git clone <URL-репозитория>
cd homework_block_2

```
2.(Опционально) Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate  # Windows
```
3.Установите зависимости:

```bash
pip install -r requirements.txt
```

### 4. Использование

Раздел с примерами использования функций. Разбейте на подразделы по функциям:
```markdown
## Использование

### filter_by_state
Фильтрует операции по статусу (по умолчанию — 'EXECUTED').

**Пример:**
```python
from src.processing import filter_by_state

# Пример входных данных
operations = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]

# Фильтрация по статусу 'CANCELED'
filtered = filter_by_state(operations, 'CANCELED')
print(filtered)
```
